Polytron Fox 350 - Smart Charging Estimator
License: MIT
Build: PWA
Stack: Vanilla JS
UI: Tailwind CSS

A lightweight web application and Progressive Web App (PWA) tailored for Polytron Fox 350 electric motorcycle owners. This utility provides precise charging time estimations using a dynamic linear calculation model, enhancing the charging management experience.

​🚀 Key Features

​💻 Technical Excellence
​Progressive Web App (PWA): Offline support via Service Workers and installable on iOS/Android as a standalone application.
​Glassmorphism UI: Modern interface design utilizing Tailwind CSS JIT engine for optimized styling.
​High-Contrast Dark Mode: Adaptive theming with a specialized slate and amber palette for low-light environments.
​Micro-Animations: Fluid SVG-based animations for real-time status indicators (pulse & glow effects).

​🔋 Core Functionality
​Charging Logic: Dynamic estimation based on SoC (State of Charge) percentage and user-defined charging rates.
​Data Persistence: LocalStorage-based history module for tracking charging sessions without external database dependencies.
​Localization: Full i18n support for Indonesian (ID) and English (EN).
​History Analytics: Session logging with date-based filtering and duration breakdown.

​🛠️ Tech Stack
​Frontend: Vanilla JavaScript (ES6+), HTML5.
​Styling: Tailwind CSS 3.x (PostCSS Architecture).
​PWA Architecture: Web App Manifest & Service Worker API.
​Persistence: Web Storage API (LocalStorage).
​Design Assets: Custom SVG Pathing & Google Fonts (Plus Jakarta Sans).
